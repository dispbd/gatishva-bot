# Страница в Facebook

Код готов и выключен: пока не заданы `FB_PAGE_ID` и `FB_PAGE_TOKEN`, бот ничего не делает с
Facebook. Почему страница, а не бот в Messenger, — в [roadmap.md](roadmap.md): Meta позволяет
написать человеку первым только в течение 24 часов после его последнего сообщения, а пост на
странице видят все её подписчики, бесплатно.

## Как работает

Страница — ещё один «чат» (`FACEBOOK_CHAT = 0`), подписанный на целые города из
`FB_PAGE_CITIES`. Поэтому она получает ровно то же, что чат в Telegram с такой подпиской:

| Событие | В Telegram | На странице |
|---|---|---|
| Новое отключение | сообщение | пост |
| Отключение изменилось | правка сообщения | правка поста |
| Отключение закончилось | правка и ответ «✅ завершено» | правка поста и комментарий |
| Сигнал жителей | сообщение | **не публикуется** — неподтверждённое не для публичной страницы |

Текст тот же, что в Telegram, на языке `FB_PAGE_LANG`, только без разметки: Facebook её не
понимает, поэтому спойлеры становятся абзацами, а ссылка на поставщика — строкой «GWP: адрес».
Подписки страницы сверяются с настройками на каждом будильнике: поменять города — значит
поменять переменную и задеплоить.

## Настройка, когда страница появится

1. **Страница.** Создать в Facebook; её ID — в «О странице» → «Прозрачность страницы» или в
   адресе.
2. **Приложение Meta.** [developers.facebook.com](https://developers.facebook.com) → My Apps →
   Create App → тип *Business*. В режиме разработки приложение может публиковать на
   страницах, где вы администратор, — для своей страницы App Review не нужен.
3. **Токен страницы.** В [Graph API Explorer](https://developers.facebook.com/tools/explorer/):
   выбрать приложение, запросить права `pages_manage_posts`, `pages_read_engagement`,
   `pages_show_list`, получить токен пользователя, обменять его на долгоживущий
   (`/oauth/access_token?grant_type=fb_exchange_token...`), затем запросить `/me/accounts` —
   токен страницы, полученный из долгоживущего токена пользователя, не истекает.
4. **Секрет и переменные:**
   ```bash
   npx wrangler secret put FB_PAGE_TOKEN
   ```
   и в `wrangler.toml`, в `[vars]`:
   ```toml
   FB_PAGE_ID = "1234567890"
   FB_PAGE_CITIES = "თბილისი"   # через запятую, по-грузински; Тбилиси по умолчанию
   FB_PAGE_LANG = "ka"          # ka, ru или en; грузинский по умолчанию
   ```
   Push в `master` — и страница начнёт публиковать с первого нового отключения: что уже
   было, она не получит, как и новый чат.

`FB_GRAPH_VERSION` — версия Graph API, `v23.0` по умолчанию; Meta поддерживает каждую версию
около двух лет, после чего её нужно поднять.

## Чего здесь нет

- **Публикации в группы.** Meta убрала API для групп в 2024 году.
- **Бота в Messenger** — отдельная ветка `feat/messenger`.
- **Объединения постов.** Каждое отключение — отдельный пост. Если их окажется слишком
  много для ленты, следующий шаг — сводка раз в час по городу.
